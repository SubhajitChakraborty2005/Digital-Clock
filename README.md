# 🕒 Digital Clock with Glow Effect

A simple and stylish **Digital Clock** built using **HTML**, **CSS**, and **JavaScript**, featuring a real-time update and a glowing neon effect for a modern aesthetic.

## ✨ Features

- Real-time display of hours, minutes, and seconds
- Glowing neon effect for a visually appealing look
- Responsive and lightweight design
- Built using Vanilla JavaScript (no frameworks)
